# JIE影视4K

高级磨砂风格影视 Web App 源码演示，支持手机和平板自适配，使用 TMDB 真实影视资料、海报和官方视频信息。

## 功能

- 首页推荐、电影、电视剧、动画动漫、正在热映分类
- 按影视 / 动画名称搜索
- 可配置 TMDB API 代理：`https://api.tmdb.org`
- 可配置 TMDB 图片代理：`https://images.tmdb.org/t/p`
- 使用本机浏览器保存 TMDB Bearer Token，不把密钥写入源码
- 官方预告片播放、内置合法 4K 演示片源播放
- 可配置自有授权播放源模板，例如 `https://cdn.example.com/video/{id}.m3u8`
- 邮箱、用户名、密码注册登录演示
- 本地收藏与观看历史

## 使用方法

1. 直接打开 `index.html`，或用任意静态服务器托管。
2. 点击右上角“设置”。
3. 填入 TMDB Bearer Token、API 代理和图片代理。
4. 如需播放完整正片，填入你拥有版权或已获授权的播放源模板。

> 说明：本项目不提供盗版影视聚合、第三方站点抓取或绕过版权的接口。生产环境请仅接入自有版权、公开视频或已授权的视频 CDN / HLS 资源。
